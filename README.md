**Kageland** is a futuristic, space-themed landing experience built around a floating island world.  
At its core lies a living 3D planet that reacts to your presence — subtle, responsive, and calm.

This project blends **Three.js** with a modern UI stack to create an immersive, cinematic web experience.

---

## ✨ Concept

Kageland is imagined as a sovereign floating planet — an archipelago suspended above luminous oceans.

- Levitating islands stabilized by flux anchors  
- Minimal drift, maximum precision  
- Governed by **King kgnio**, ruler by design and discipline  

The website acts as an interactive planetary briefing rather than a traditional landing page.

---

## 🧠 Experience Design

- Central **3D island** rendered with `@react-three/fiber`
- Mouse-driven rotation for a sense of presence
- Minimal futuristic UI panels orbiting the scene
- Black space background with subtle starfield motion
- Clean typography and glass-like interfaces

Nothing flashes. Nothing shouts.  
Everything moves with intent.

---

## 🛠️ Tech Stack

- **Next.js (App Router)**
- **Three.js** + `@react-three/fiber`
- **@react-three/drei**
- **shadcn/ui**
- **Tailwind CSS**
- **Radix UI**
- **GLTF / GLB 3D assets**

---

## 🚀 Features

- Responsive full-screen 3D canvas
- Smooth mouse-follow rotation (yaw + subtle tilt)
- Minimal HUD-style loading indicator
- Futuristic glass cards and navigation
- Layered pointer-event control for seamless interaction
